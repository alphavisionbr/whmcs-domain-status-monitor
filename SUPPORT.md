# Suporte

Antes de abrir uma Issue, consulte o `README.md`, o `CHANGELOG.md` e a documentação em `docs/`.

Ao relatar um problema, informe:

- versão do módulo;
- versão do WHMCS;
- versão do PHP;
- banco de dados utilizado;
- resultado da aba Diagnóstico;
- se `/etc/resolv.conf` está acessível;
- comportamento esperado;
- comportamento observado;
- passos para reprodução.

Anonimize domínios, hostnames, IPs, nameservers e demais dados reais do ambiente.
